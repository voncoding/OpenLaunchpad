常见问题

开始之前，
你可能想知道。

这是 Apple 官方的启动台吗？

不是。OpenLaunchpad 是独立开发的开源应用，使用 SwiftUI 和 AppKit 构建，与 Apple 无隶属关系。

需要付费或注册账号吗？

不需要。OpenLaunchpad 免费使用，源代码采用 MIT 许可，可以在 GitHub 查看。

Intel Mac 可以使用吗？

可以。v1.1.1 提供通用安装包，同时包含 Apple Silicon 和 Intel 版本，要求 macOS 26.0 或更高版本。

如何从旧版更新？

先退出正在运行的启动台，下载并解压 v1.1.1，将新的 OpenLaunchpad.app 替换到「应用程序」中，再重新打开。已有排序、文件夹、网格与应用显示设置会保留。若更新后照片壁纸无法读取，请查看下方权限说明。

macOS 27 下壁纸不显示怎么办？

先在启动台设置中查看“壁纸”状态。若提示权限不足，可在“系统设置 → 隐私与安全性 → 完整磁盘访问”中添加当前安装的启动台，再退出并重新打开。此权限范围大于壁纸目录；也可以在系统壁纸设置中改用本地图片文件，再点“重新读取壁纸”。安装包使用临时签名，更新后可能需要重新添加授权。

首次打开时，macOS 提示无法验证怎么办？

当前发布包使用临时签名，尚未经过 Apple 公证。请确认下载来源是本项目的 GitHub Releases；确认后，可按 macOS 提示前往「系统设置 → 隐私与安全性」选择「仍要打开」。
